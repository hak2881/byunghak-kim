- 굵은 제목, 충분한 여백, 얇은 구분선
- 수치와 기술적 결과는 큰 숫자와 짧은 라벨로 표현
- 시스템 카드에는 설명, 직접 기여, 기술 태그, 공개 사례 링크를 제공

- 애니메이션은 언어 전환과 링크 호버 정도만 사용하고 `prefers-reduced-motion`을 존중한다.
- 기술 숙련도 막대와 터미널 콘셉트는 사용하지 않는다.

## 기술 구조

프로젝트는 정적 파일만 사용한다.

- `index.html`: 시맨틱 문서 구조, 기본 한국어 콘텐츠, 메타데이터
- `styles.css`: 반응형, 접근성, 인쇄 스타일
- `app.js`: 언어 전환, 선택 언어 저장, 이메일 복사, 인쇄 호출
- `og.png`: 사이트 전용 소셜 공유 이미지
- `robots.txt`: 공개 크롤링 허용
- `sitemap.xml`: 최종 프로덕션 URL 반영
- `vercel.json`: 필요한 경우에만 보안 헤더와 정적 라우팅을 선언

빌드 단계와 런타임 함수는 두지 않는다. `index.html`은 JavaScript가 실패해도 한국어 이력서로 완전히 읽혀야 한다.

## 다국어 동작

- 한국어를 기본 언어로 한다.
- 각 번역 대상 요소에 `data-ko`와 `data-en` 값을 둔다.
- 페이지 로드 시 `localStorage`의 `resume-language` 값을 읽고 없으면 한국어를 사용한다.
- 전환 버튼은 `lang` 속성, 버튼의 `aria-pressed`, 표시 문구를 함께 갱신한다.
- 영어 문구는 한국어의 의미와 역할 경계를 그대로 유지한다.
- 검색엔진과 비 JavaScript 환경에서 기본 한국어 콘텐츠가 보인다.

## 주요 상호작용

### 언어 전환

버튼 한 번으로 페이지 전체가 KR 또는 EN으로 전환된다. URL 이동이나 새로고침은 필요 없다.

### 이메일 복사

클릭 시 이메일을 클립보드에 복사하고 짧은 상태 메시지를 보인다. Clipboard API를 사용할 수 없으면 `mailto:` 링크는 그대로 작동한다.

### 인쇄/PDF

Print 버튼은 `window.print()`를 호출한다. 인쇄 CSS는 내비게이션, 버튼, 장식적 배경을 숨기고 A4 세로에서 섹션이 부자연스럽게 잘리지 않도록 한다.
